SecuroTalk — End-to-End Encrypted Messaging

End-to-end encrypted messaging web platform engineered for maximum privacy and user autonomy. Messages, voice memos, and image media are encrypted client-side using hybrid cryptography before transit, ensuring zero plaintext exposure to intermediate relays.

React Node.js Socket.io Web Crypto API IndexedDB Firebase Auth FCM Notifications PWA
Hybrid Cryptography: E2E encryption for text, voice notes, and media via Web Crypto API.
Zero Server Storage: All chat records and keys persist strictly in user browser IndexedDB.
Real-time Sockets: Double-tick delivery receipts, typing indicators, and presence telemetry.
Push Notifications: Background alerts for new encrypted payloads even when app is inactive.
Remote Deletion: Granular "Delete for me" and remote "Delete for everyone" sync.
PWA & Custom Media: Installable mobile experience with custom voice player & full-res downloads.
Privacy Architecture: Only the intended recipient can decrypt messages. The backend relays encrypted ciphertext blobs and never has access to private decryption keys or plaintext metadata.
