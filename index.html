End-to-end encrypted messaging web app focused on maximum privacy and user control (text + media).

  • End-to-end encrypted communication for text, voice, and images (Hybrid Encryption using Web Crypto API)
  • No server-side message storage — conversation data persisted in user's browser (IndexedDB)
  • Real-time messaging via Socket.io (double-tick delivery receipts)
  • Real-time push notifications for new messages even when the app is closed (FCM + Service Worker)

  • Single-device-per-account enforcement (session binding)

  • Custom media UI: audio player for voice notes and thumbnail previews for images with one-click full-resolution download
  • Account creation + sign-in (Google auth via Firebase)
  • Progressive Web App (PWA) support for installable chat experience
